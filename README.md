# 🚀 My AI Experiments & Learning Path

Welcome to my playground! This repository is a living document of my journey into the world of Generative AI, Local LLMs, and AI Agents. 

## 🎯 Goals
My primary focus is to move from using AI as a consumer to building AI-powered systems. I'm currently experimenting with:
- **Local LLM Deployment**: Testing open-source models (Llama 3, Mistral) on consumer hardware.
- **RAG Implementation**: Building a simple pipeline to chat with my own documents.
- **Agentic Workflows**: Exploring how to make LLMs use tools to solve complex tasks.

## 🛠️ Current Tech Stack (Exploring)
- **Language**: Python 3.10+
- **Libraries**: LangChain, PyTorch, FAISS
- **Models**: Llama-3-8B, Mistral-7B-v0.3
- **Target Hardware**: Moving towards AMD GPU / ROCm for better performance/efficiency.
